# data/

Put `global_placement.csv` here (10,000 rows, 13 columns), then run `python train.py`.

Expected columns:

```text
cgpa, backlogs, college_tier, country, university_ranking_band,
internship_count, aptitude_score, communication_score, specialization,
industry, internship_quality_score, placement_status, salary
```

The CSV is not committed to this repository (see `.gitignore`), because its
source licence has not been verified.
