# Global Career Predictor

AI-powered employment opportunity and salary prediction.

## Problem

> Analyze global salary data to predict wage levels and employment opportunities.

## Solution

A two-stage Random Forest system served through a Flask web app:

```text
Student profile
   → Employment classification (Placed / Not Placed)
   → Placement probability
   → Salary regression (only if predicted Placed)
   → Explainable AI insights and what-if analysis
```

- **AI Profile Insights**: compares each numeric input with the training data
  (top 25% / typical / lower 25%).
- **What the model relies on most**: the top features of each model by
  relative feature importance.
- **What-if analysis**: re-runs the trained model with one input changed at a
  time, to show how the model responds.

## Dataset

`global_placement.csv`:

- 10,000 records, 13 original columns, no missing values
- 6,153 Placed / 3,847 Not Placed
- 11 input features, 2 targets (`placement_status`, `salary`)

The dataset is **not included** in this repository. See
[data/README.md](data/README.md) for where to place it.

## Features

- CGPA
- Backlogs
- College tier
- Country
- University ranking band
- Internship count
- Aptitude score
- Communication score
- Specialization
- Industry
- Internship quality score

Categorical features are one-hot encoded (`pd.get_dummies`, `drop_first=True`).
Numerical features are used as they are.

## Models

Both models: Random Forest, 200 trees, `random_state=42`, 80/20 train/test split.

### Placement: Random Forest Classifier

Trained on all 10,000 records (8,000 train / 2,000 test, stratified).
`salary` is excluded from the inputs to avoid target leakage.

| Metric | Value |
|---|---|
| Accuracy | 74.40% |
| Baseline (always predict majority class) | 61.55% |
| F1: Placed | 0.80 |
| F1: Not Placed | 0.64 |

### Salary: Random Forest Regressor

Trained only on students who were placed (4,922 train / 1,231 test).

| Metric | Value |
|---|---|
| MAE | 4,224.11 |
| R² | 0.9480 |
| Average test salary | 91,071.55 |
| MAE / average salary | 4.64% |

**R² is not accuracy.** It is the proportion of variance in salary explained
by the model on the test set.

**Feature importance shows model reliance, not causation.** It indicates which
inputs the Random Forest uses most when making predictions. It does not mean
that changing an input would cause a real-world change in placement or salary.

## How to Run

```bash
# 1. Create and activate a virtual environment
python3 -m venv venv
source venv/bin/activate

# 2. Install dependencies
pip install -r requirements.txt

# 3. Place the dataset at data/global_placement.csv

# 4. Train the models (once; saves them to models/)
venv/bin/python train.py

# 5. Start the web app
venv/bin/python app.py
```

Open <http://127.0.0.1:5000>.

Trained models are not committed (about 130 MB). `train.py` regenerates them
reproducibly. It was tested with Python 3.12, Flask 3.1.3, pandas 3.0.6,
scikit-learn 1.9.1 and joblib 1.6.0.

packages (`google.colab`, `matplotlib`, `seaborn`) that the app does not need.

## Limitations

- The dataset's source and collection method are not documented in this
  repository, so results may not reflect real labour markets.
- The placement model performs unevenly across classes: recall is higher for
  Placed than for Not Placed (F1 0.80 vs 0.64).
- Salary feature importance is dominated by geographic and institutional
  variables (country, college tier).
- The salary currency is not documented in the dataset. The web page displays
  ₹ (`CURRENCY_SYMBOL` in `ml_config.py`).
- Inputs are limited to the value ranges seen in the training data.
- Predictions are model estimates, not guarantees of employment or salary.
